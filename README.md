# slangspel_blok2
Dit is de blok twee project waar wij gaan de spel "slangspel" maken.
Plan van Aanpak – Slang Spel

Projectomschrijving
We gaan een slang spel (Snake Game) maken waarbij de speler eten verzamelt om punten te verdienen en langer te worden. Het spel stopt wanneer de slang tegen de muur of zichzelf botst.

Doel
Het doel is om meer ervaring te krijgen met programmeren, bewegingen, gebruikersinput en game logica.

Functionaliteiten
Slang besturen met toetsenbord
Eten laten verschijnen
Score systeem
Game over scherm
Gebruikte technieken
Programmeertaal: JavaScript / Python / C#
Game loop
Toetsenbord input
Planning
Ontwerp maken
Beweging van slang programmeren
Eten en score toevoegen
Botsingen maken
Testen en verbeteren

Eindresultaat
Een werkend slang spel dat speelbaar is op de computer.
